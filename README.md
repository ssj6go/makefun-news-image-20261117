# The World in One Day — Tuesday, 17 November 2026

One image summing up the world's news of Tuesday 17 November 2026, drawn
programmatically as a newspaper front page: a masthead naming the day, one
lead story, four more stories across regions and fields, and two more in the
footer strip. `main.ts` (Node 22, standard library only) copies `entry.png`
to `/output/entry.png`.
